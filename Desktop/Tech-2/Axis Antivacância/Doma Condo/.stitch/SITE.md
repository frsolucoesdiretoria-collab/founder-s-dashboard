# DOMA CONDO — Site Vision & Roadmap

## 1. Vision

App de gestão para BPO financeiro de condomínios. Jéssica (admin) e suas 2 funcionárias registram atividades financeiras diárias via WhatsApp. App consolida tudo: trabalho feito, tarefas pendentes, relatórios PDF por cliente.

**Objetivo imediato:** Casca completa navegável com dados mock para apresentação à cliente na segunda-feira. Sem backend — tudo estático/mock.

## 2. User Roles

| Role | Acesso | Sidebar |
|------|--------|---------|
| Admin (Jéssica) | Visão completa | Escura com gold |
| Funcionária | Visão própria | Simplificada |
| Cliente | Portal read-only | Clara, minimal |

## 4. Sitemap

### Admin Pages
- [ ] login — Tela de login
- [ ] dashboard — Dashboard principal com KPIs e gráficos
- [ ] priorities — Priorização do dia por cliente
- [ ] team — Lista da equipe (funcionárias)
- [ ] team-detail — Detalhe de funcionária (tabs: atividades, tarefas, mensagens)
- [ ] clients — Lista de clientes (administradoras)
- [ ] client-detail — Detalhe de cliente (tabs: condomínios, atividades, tarefas, relatórios)
- [ ] tasks — Kanban de tarefas (pendente / em andamento / concluída)
- [ ] work-logs — Registro de atividades (tabela + timeline)
- [ ] reports — Lista de relatórios PDF
- [ ] report-preview — Preview do relatório (simulação do PDF)
- [ ] categories — Gestão de categorias de atividades
- [ ] messages — Chat WhatsApp (lista conversas + view)
- [ ] settings — Configurações (organização, WhatsApp, Drive, usuários)

### Employee Pages
- [ ] my-work — Meu trabalho (work logs da funcionária)

- [ ] my-messages — Minhas mensagens com o bot

- [ ] portal — Visão geral do cliente
- [ ] portal-activities — Atividades do cliente

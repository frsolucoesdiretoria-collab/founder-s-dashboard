Já temos a API Key do Trello configurada

Só precisamos do seu Token de autorização e do ID do quadro que você quer conectar.

1

Autorizar o acesso ao Trello

Clique no botão abaixo. O Trello vai abrir e pedir sua permissão. Clique em "Permitir".

open_in_new Clique aqui para autorizar o Trello

O que vai aparecer:

Depois de clicar em "Permitir", o navegador vai mostrar uma sequência longa de letras e números (parece algo como a1b2c3d4e5f6g7...). Copie esse código e cole no campo abaixo.

Deve ter cerca de 64 caracteres — letras e números sem espaços.

2

Pegar o ID do quadro

Abra o Trello e navegue até o quadro que você usa para organizar os trabalhos da Doma Condo.

Olhe o endereço do navegador. Vai ser assim:

trello.com/b/XXXXXXXX/nome-do-quadro

A parte em destaque — depois do /b/ e antes do próximo / — é o ID. Geralmente tem 8 caracteres.

8 caracteres que aparecem na URL do quadro.

schedule

Esta etapa leva cerca de 10 a 15 minutos. Siga os passos na ordem — cada um depende do anterior.

1

Abrir o Google Cloud Console com a conta da Doma Condo

Use a conta Google da empresa, não uma conta pessoal.

open_in_new Abrir Google Cloud Console
2

Criar um novo projeto

→ No canto superior esquerdo, clique no nome do projeto (onde diz "Selecionar projeto" ou o nome de um projeto existente)

→ Clique em "Novo Projeto"

→ Nome: DomaCondo App

→ Clique em "Criar" e aguarde alguns segundos

3

Ativar a API do Google Drive

→ No menu lateral esquerdo: APIs e Serviços → Biblioteca

→ Na busca, escreva: Google Drive API

→ Clique no resultado e depois clique em "Ativar"

4

Configurar a Tela de Consentimento (só na primeira vez)

→ Menu lateral: APIs e Serviços → Tela de consentimento do OAuth

→ Selecione "Externo" → Clique em "Criar"

→ Preencha apenas: Nome do app = DomaCondo, e o e-mail nos dois campos de e-mail

→ Clique em "Salvar e Continuar" em todas as telas até o fim

→ Clique em "Voltar para o painel"

5

Criar as credenciais OAuth e copiar os dados

→ Menu lateral: APIs e Serviços → Credenciais

→ Clique em "+ Criar Credenciais → ID do cliente OAuth"

→ Tipo de aplicativo: "Aplicativo da Web"

→ Nome: DomaCondo Web

→ Em "URIs de redirecionamento autorizados", clique em "+ Adicionar URI" e cole exatamente:

http://localhost:3000/auth/google/callback

→ Clique em "Criar"

⚠️ Atenção: vai aparecer uma janela com dois códigos

Copie os dois e cole nos campos abaixo antes de fechar a janela. Se fechar sem copiar, precisará criar novamente.

Este campo está oculto por segurança — os caracteres aparecem como pontos.

6

Pegar o ID da pasta principal do Drive

Abra o Google Drive e navegue até a pasta principal onde ficam os arquivos dos seus clientes (condomínios).

Olhe o endereço do navegador. Vai ser assim:

drive.google.com/drive/folders/1BxiMVs0XRA5nFMdKv...

Copie tudo que vem depois de /folders/

info

O Gather é o escritório virtual da Doma Condo. O sistema monitora as entradas e saídas das colaboradoras para registrar os turnos automaticamente.

1

Pegar o ID do espaço

Abra o Gather no navegador e entre no espaço da Doma Condo.

open_in_new Abrir Gather

Quando estiver dentro do espaço, olhe o endereço do navegador:

app.gather.town/app/SPACE_ID/nome-do-espaco

O Space ID fica entre /app/ e o próximo /. Pode conter %2F no meio — copie tudo mesmo assim.

2

Gerar a chave de API

Acesse a página de chaves do Gather com a mesma conta.

open_in_new Abrir página de API Keys do Gather

→ Clique em "Generate New Key"

→ Dê o nome: DomaCondo Bot

→ Copie a chave que aparecer imediatamente

⚠️ A chave só é exibida uma vez

Se fechar a página sem copiar, vai precisar gerar uma nova.

Campo oculto por segurança.

Como vai funcionar

O sistema vai conectar um número de WhatsApp para enviar os relatórios diários para você e receber os registros das colaboradoras. O número continua funcionando normalmente no celular — o sistema apenas envia e recebe em paralelo.

1

Número do WhatsApp do sistema

Qual número será usado para o sistema enviar e receber as mensagens? Pode ser um número dedicado ou o número do escritório.

Formato: 5511999999999 (55 = Brasil, 11 = DDD, sem espaços)
2

Seu número (Jéssica)

Os relatórios diários e notificações serão enviados para este número.

3

Colaboradoras que vão usar o sistema

Nome e WhatsApp de cada colaboradora que vai registrar o trabalho diário.

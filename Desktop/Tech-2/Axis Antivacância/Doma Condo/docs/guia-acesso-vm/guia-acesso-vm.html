4

Adicione as duas funções (permissões)

No campo "Atribuir função", clique e busque as duas funções abaixo. Adicione as duas.

key

Função 1

Compute OS Login

Permite acesso SSH à máquina virtual

visibility

Função 2

Viewer (Leitor)

Permite visualizar os recursos do projeto

Como adicionar as duas funções:

  1. 1 Clique em "Selecione uma função" → no campo de busca, digite Compute OS Login → clique para selecionar
  2. 2 Clique em "+ Adicionar outra função" (link azul que aparece logo abaixo)
  3. 3 No novo campo, busque Viewer → clique para selecionar

Aparência após selecionar as duas funções:
